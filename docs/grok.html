Grok card-stack technique

Side-by-side demo of the QMail list bug versus the recommended fix from grok.card-recs.txt: stop flex shrink, opaque card faces with a top-light gradient, explicit z-index elevation, and a “draw from the deck” hover — without content of one row living in another row’s hit box.

Selected (click a card) Unread tint Right column = recommended technique

Broken (current accident)

flex-shrink + transparent paint

Many rows + flex-shrink: 1 + min-height: 4.5rem squashes boxes; content overflows. Click where an avatar looks like it belongs to one mail — often selects the neighbor. Selection washes out.

Fixed (recommended)

flex: 0 0 auto · opaque · z-index · fan chrome

Natural height always. Opaque gradient cards, micro fan offsets, pseudo edge layers with pointer-events: none, hover lifts with z-index 5. What you see is what you hit.

Click any card. Selection is reported here.

Technique checklist (this demo)

  1. Geometry: flex: 0 0 auto so rows never squash below content.
  2. Opaque faces: tints mix into --secondary-bg, never into transparent.
  3. Depth gradient: lighter top edge → darker bottom (stacked-paper read).
  4. Stack layers: ordinary 1 · selected 3 · hover/focus 5.
  5. Deck hover: translateY + scale + shadow, not neighbor overflow.
  6. Fan illusion: tiny --fan-x offsets + non-interactive ::before/::after edges.
