Codex change report: GUI refresh echo de-duplication follow-up
Date: 2026-06-19

Problem
-------
A manual refresh still caused extra /raida/echo traffic after the first GUI
fix:

1. QMailDashboard.handleRefresh() called echoRaida() and stored the result in
   raidaEchoSnapshot, but NavigationPane only used that snapshot for the RAIDA
   panel. When isRefreshing flipped back to false, NavigationPane immediately
   ran checkServerHealth(), which echoed again.
2. If NavigationPane's echo failed, it passed null to getServers(). getServers()
   treated null as "no shared echo was supplied" and immediately called
   /raida/echo itself, creating a second echo on the failure/rate-limit path.

Changes
-------
src/api/qmailApiServices.js
- getServers now accepts skipEcho.
- getServers now distinguishes an explicitly supplied echoData property from a
  missing echoData property. Passing echoData: null with skipEcho: true means
  "do not echo; mark server availability unknown."
- Existing getServers() callers remain backward compatible: calls with no
  options still fetch topology and one echo.

src/qmail/screens/NavigationPane.jsx
- Added wasRefreshingRef so the automatic health-check effect does not run an
  immediate checkServerHealth() right after a manual refresh completes. The
  normal 120-second interval is still restarted.
- Added applyQmailServersFromEcho() so QMail server status can be derived from
  an already-fetched echo without another echo call.
- checkServerHealth() now calls getServers({ echoData, skipEcho: true }) even
  when echoData is null, preventing the failure path from re-echoing.
- The raidaEchoSnapshot effect now updates both the RAIDA panel and the QMail
  server panel from the same parent refresh echo.

Expected Result
---------------
A manual refresh uses the single /raida/echo call owned by QMailDashboard for
both the RAIDA and QMail status panels. NavigationPane no longer performs a
second echo immediately after refresh, and getServers no longer retries echo
when told that echo has already been attempted.
