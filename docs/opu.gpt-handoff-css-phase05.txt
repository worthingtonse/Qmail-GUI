Q1. Class name — is `.field-hint` the right name?
    ---------------------------------------------
    Alternatives I considered:
      .auth-tab__hint     too narrow (lives in 3 different tabs)
      .form-hint          generic; might collide with future form-
                          related classes in Phase 3
      .input-hint         narrow too — the <small> sits beside the
                          input but it isn't a child of <input>
      .help-text          most accessible-pattern-friendly name
      .tab-hint           wrong scope ("tab" reads as nav-tab)

    I went with `.field-hint` because:
      - Semantically the <small> sits under a form-field label
      - The pattern doesn't depend on which tab hosts it
      - "field" is the natural ARIA-y term for input + label
        + hint, even though we don't formally use field-set markup
      - Phase 3's likely primitive layer would land it as
        .field-hint inside .field-shell or similar — short
        rename if needed

    Push back if you'd pick a different name.


Q2. Location — should `.field-hint` live in src/index.css or wait
    for Phase 3 / primitives.css?
    -----------------------------------------------------------
    Putting it in index.css NOW means:
      + Ships the fix immediately, no new file
      + Lives next to other global helpers (h1-h6, code, p)
      + If Phase 3 creates primitives.css and we move it there,
        index.css stays the canonical import chain (per plan v2.4
        item 6 / item 6's wiring step)

    Drawbacks:
      - Mixes "global resets + typography" with "shared component
        helpers" in one file
      - If Phase 3 doesn't ship soon, we accumulate more of these
        helpers in index.css and it becomes a junk drawer

    The alternative would have been: defer Phase 0.5 entirely
    until Phase 3 / primitives.css ships. That kept appearing to
    you as a reasonable position but I went the other way because
    the `#666` literal was a real debt leak — getting rid of it

    Is the home okay, or would you have done it differently?
