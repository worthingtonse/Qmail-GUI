Fixes applied in this pass
--------------------------
1. ComposeModal reply / replyAll / forward body construction crashed if
   sourceEmail.body was null/undefined even when isDownloaded was true.
   - selectedEmail can briefly hold an isDownloaded=true row with an
     empty/missing body (e.g. between list hydration and the
     getEmailById merge in handleSelectEmail).
   - `sourceEmail.body.replace(/\n/g, "\n> ")` on null throws and
     leaves the modal stuck on a blank body.
   - Fix: coerce to `(sourceEmail.body || "").replace(...)` in all three
     branches and store the safe value in an `originalBody` local.

2. Forward header rendered "From: undefined <addr>" when sourceEmail
   had no `sender` display name.
   - The composed header used `${sourceEmail.sender} <${addr}>`
     unconditionally.
   - Fix: fall back to "Unknown" for the display name and OMIT the
     angle-bracketed address entirely when no address is available
     (renders "From: Unknown" instead of "From: Unknown <>").

3. Reply / Reply All wrote `undefined` into the quoted-body header when
   `sourceEmail.timestamp` was missing.
   - Same defensive coercion: `${sourceEmail.timestamp || ""}`.
   - Reply also now falls back to sourceEmail.from when neither sender
     nor senderEmail is set (was missing the `from` fallback that the
     forward branch already had).

4. sendProgress and showAdvanced reset was scoped to the "new" branch
   only; reply / replyAll / forward / draft branches inherited stale
   state when the modal was reopened in a different mode without a
   page reload.
   - Reopening compose after a send-progress message left the prior
     status text visible until the next user action.
   - The Advanced Options pane stayed expanded across modal opens.
   - Fix: hoist `setSendProgress("")` and `setShowAdvanced(false)` out
     of the new-message branch and run them unconditionally at the end
     of the mounting useEffect, alongside the other modal-wide resets
     (setAttachments, setError, etc.) that were already mode-agnostic.
