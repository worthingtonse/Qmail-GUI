QUICK REFERENCE - STARTUP FLOW:
================================================================================

1. QMail.exe starts → Electron main process (electron.cjs)
2. Reserve random port for backend (or use --port flag)
3. Start core.exe on that port via spawn() [takes 5-7 seconds to bind]
4. Create splash screen
5. Create main window (hidden) loading http://localhost:PORT/?backendPort=PORT
6. Frontend loads (dist/index.html + index-*.js)
7. App.jsx mounts, useEffect triggers:
   a) waitForBackend() probes /api/system/version-check until responds [BLOCKING]
   b) Parallel: checkForUpdates() + checkIdentity()
   c) checkIdentity():
      - Calls getIdentity() → fail if backend not ready
      - Falls back to hasId() → fail if backend not ready
      - If both fail, shows ServiceSelectionScreen
   d) setIsLoading(false) → render service
8. If backend is now ready, identity check succeeds → show QMail dashboard
9. If backend not ready yet, show locker prompt until later API call succeeds
