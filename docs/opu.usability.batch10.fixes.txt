Reviewer-Focus Answers
----------------------
(From gpt.usability.batch10.summary.txt "Reviewer Focus" block.)

1. "Send anyway" override vs. silently enabling Send when canSend
   === false: AGREE with the explicit relabel. It signals to the
   user that they're choosing to ignore a warning, and the title
   attribute confirms "the backend will make the final network
   decision." Matches the FIX-22 spec.

2. Warning path avoiding the red form-level error slot: AGREE.
   Validation errors are red (compose can't proceed), network
   uncertainty is amber (compose probably will proceed). The two
   classes of message MUST stay visually distinct so users don't
   learn to dismiss the red banner.
