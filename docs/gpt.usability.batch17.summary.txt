Batch 17 Summary - FIX-42 + FIX-43 + FIX-45
============================================

Scope
-----
Implemented Phase 3 Batch 17:
- FIX-42: Add a Contacts SN/email lookup helper.
- FIX-43: Treat NavigationPane folder icons as default-with-override.
- FIX-45: Rename RAIDA network balance-card classes.

Also folded in nearby reviewer bugs:
- BUG-44: Derive DRD saved state from saved contacts instead of component memory.
- BUG-47: Avoid ContactsPane undo click refreshing local state after unmount.
- BUG-48: Keep contact delete errors inline by explicit design.

Changes
-------
FIX-42:
- Added a Contacts Lookup mode beside Contacts and Popular.
- Serial-number lookup first checks saved contacts, then uses the existing
  local QMail SN-to-email helper.
- Address/name lookup is clearly local-only: it searches saved contacts and
  does not query the DRD or pretend address-to-SN lookup exists.

FIX-43:
- Moved default folder icon mapping outside NavigationPane.
- Added an allowed override map for backend folder.icon/folder.iconName values.
- Unknown folders still fall back to Mail.

FIX-45:
- Network status cards now use balance-card network-online,
  balance-card network-offline, and balance-card network-unknown.
- Wallet balance cards keep their existing total/verified/counterfeit/suspect
  classes.

Adjacent BUG fixes:
- DRD Add-to-Contacts saved state is derived from saved contact serial/address/name
  matches, so it survives remount and follows delete/add changes.
- Undo restore no longer calls loadContacts from the notification click closure.
  The contact is restored through the backend; the next ContactsPane mount or
  refresh fetches the canonical list.
- Delete-confirm errors remain inline so the destructive modal stays open for
  retry; the code now documents that exception.
