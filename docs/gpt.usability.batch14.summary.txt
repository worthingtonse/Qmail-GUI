Scope

Implemented Phase 2 Batch 14:
- FIX-28: Replace ContactsPane window.confirm delete flow.

Changes
-------
FIX-28:
- ContactsPane no longer uses window.confirm() for deleting contacts.
- User contact delete now opens an in-app confirmation modal with Cancel and
  Delete actions.
- The modal blocks duplicate delete attempts while the backend request is in
  flight and shows an inline error if delete preparation or deletion fails.
- Successful delete refreshes the contacts list.
- Added a clickable undo notification after delete completes. Clicking it
  calls addContact() with the just-deleted contact data and refreshes contacts
  again on success.
