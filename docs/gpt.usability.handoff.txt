Important current API wiring to inspect
---------------------------------------
qmailApiServices.js currently has these relevant flows:

  sendEmail()
    POST /api/qmail/net/messages/upload_and_tell
    Sends URL-encoded body with repeated to/cc/bcc, subject, body, duration,
    and repeatable attachment_file_path if emailData.attachments contains
    server-side paths.

  getTaskStatus()
    GET /api/system/tasks?task_id=...
    Maps payload.status/progress/message/data to ComposeModal fields.

  importCredentials()
    GET /api/qmail/raida/locker/import-credentials?locker_key=...&wallet_path=...
    Currently discovers wallet_path from /api/wallets/list if none is passed.
    This is risky if it selects Default rather than Mail.

  getServers()
    GET /api/qmail/local/status plus GET /api/raida/echo
    Merges topology with live availability.

  syncData()
    Local stub returning unsupported. No backend call.

  Receive/read/attachment-related calls:
    GET  /api/qmail/db/notifications/list
    POST /api/qmail/net/messages/download?file_guid=...
    GET  /api/qmail/db/messages/get?email_id=...
    GET  /api/qmail/db/attachments/list?email_id=...
    GET  /api/qmail/db/attachments/get?email_id=...&attachment_id=...

  Folder/list calls:
    GET    /api/qmail/db/messages/list?folder=...
    GET    /api/qmail/db/folders/list
    GET    /api/qmail/db/folders/counts
    POST   /api/qmail/db/messages/set-read?email_id=...&is_read=...
    POST   /api/qmail/db/messages/set-star?email_id=...&starred=...
    POST   /api/qmail/db/messages/move?email_id=...&folder=...
    DELETE /api/qmail/db/messages/trash?email_id=...
    DELETE /api/qmail/db/messages/delete?email_id=...

Likely usability/completeness questions
---------------------------------------
Review as if you are a normal email user. At minimum, check:

1. First-run identity setup
   - Can a user import a locker code and land in a working QMail account?
   - Does it target the Mail wallet rather than Default?
   - Does it verify identity after import before entering QMail?

2. Compose and send
   - Can a user enter To/CC/BCC, subject, body, and send?
   - Does contact suggestion work well enough?
   - Does send progress accurately poll the backend async task?
   - Does failure messaging show actionable backend errors?
   - Does the Send button correctly disable when RAIDA availability is too low?
   - Does Compose have a real attachment picker? Current sendEmail supports
     attachment_file_path values, but ComposeModal currently appears to pass
     `attachments: []` and the Paperclip icon/import is unused.

3. Receive/read mail
   - Does the dashboard poll/list pending notifications?
   - Can a pending encrypted message be downloaded/decrypted into a readable
     message?
   - Does selecting already-downloaded mail fetch the full body and attachments?
   - Are unread counts updated after reading?

4. Attachments
   - Can the user see incoming attachments?
   - Can the user download attachments with sensible filenames?
   - Can the user send attachments from local files, or is only server-side
     path plumbing present?

5. Normal email-client functions
   - Inbox, Sent, Drafts, Trash, Starred, Archive behavior.
   - Search, sorting, pagination.
   - Move to folder, trash, permanent delete.
   - Reply flow and quoted original body.
   - Save draft and edit draft.
   - Contacts list/create/delete and popular contacts.

6. Account/status views
   - Does AccountPane show real RAIDA status with correct server labels?
   - Is the dead Sync Directory action hidden/disabled or still confusing?
   - Does the UI distinguish service health, RAIDA health, wallet balance, and
     QMail identity health?
